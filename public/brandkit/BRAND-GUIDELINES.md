## Typography

### Display: Fraunces / Cormorant Garamond
- **Role:** Headlines, brand name, section titles
- **Weight:** 500-700
- **Tracking:** 0.005em - 0.06em
- **Case:** Uppercase for headlines
- **Fallback:** Georgia, serif

### Body: Helvetica Neue
- **Role:** Body text, descriptions, UI elements
- **Weight:** 400-500
- **Tracking:** 0 - 0.12em
- **Case:** Sentence case or uppercase for labels
- **Fallback:** Helvetica, Arial, sans-serif

### Type Scale

| Element | Size | Weight | Tracking |
|---------|------|--------|----------|
| Cover H1 | clamp(3rem, 11vw, 7rem) | 500 | 0.06em |
| Section Title | clamp(2.5rem, 7vw, 4.3rem) | 700 | 0.005em |
| Subtitle | clamp(1.7rem, 4.5vw, 2.5rem) | 800 | 0.01em |
| Body | 0.92rem | 400 | 0 |
| Caption | 0.72rem | 500 | 0.2em |
| Badge Name | 1.05rem | 400 | 0.42em |
